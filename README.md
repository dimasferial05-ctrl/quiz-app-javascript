# Frontend Quiz App (Vanilla JS)

Proyek ini adalah aplikasi kuis berbasis browser tantangan dari [roadmap.sh]([https://roadmap.sh/](https://roadmap.sh/projects/quiz-app)) yang dibangun menggunakan HTML, CSS, dan Vanilla JavaScript. Fokus utama proyek ini adalah pengelolaan *state* aplikasi yang cukup kompleks, logika waktu (*timer*), serta manipulasi DOM secara dinamis.

## ✨ Fitur Utama

- **Sistem Scoring:** Skor bertambah otomatis jika jawaban benar.
- **Feedback Instan:** Tombol pilihan akan berubah warna menjadi hijau (benar) atau merah (salah) segera setelah diklik, serta menunjukkan jawaban yang benar.
- **Timer & Penalti:** Setiap pertanyaan memiliki batas waktu 60 detik. Jika waktu habis sebelum dijawab, skor akan dikurangi 1 poin sebagai penalti.
- **Dynamic UI:** Alur aplikasi yang mulus mulai dari layar awal, sesi kuis, hingga ringkasan hasil akhir.
- **Responsive Design:** Tampilan kuis yang optimal di berbagai ukuran layar.

## 📂 Struktur Proyek

- `index.html` - Struktur utama aplikasi (Start, Quiz, & Result screen).
- `style.css` - Desain antarmuka dan indikator status jawaban.
- `script.js` - Logika utama, pengelolaan data kuis, timer, dan kalkulasi skor.

## 🛠️ Teknologi yang Digunakan

- **HTML5**
- **CSS3** (Flexbox, UI States)
- **JavaScript (ES6)** (Intervals, DOM Manipulation, Array Methods)
